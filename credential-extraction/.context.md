# Module: credential-extraction

## Purpose

End-to-end harness for capturing the Kohler Konnect Android app's APIM
service-account JWT (`GET /token/api/v1/token/`), plus legacy static
credential extraction. The capture is the input to the auth rewrite — see
`working/findings/auth_architecture_2026-05-10.md`.

## Key files

- `Makefile` — the entry point. `make help` shows the user journey. Real
  dependency graph: every tool the harness needs is a file target
  (`$(BREW_PREFIX)/bin/adb`, `$(VENV)/bin/frida`, `$(SDKMANAGER)`, etc.) so
  `make deps` is idempotent without `brew list` shell-outs. `harness`
  depends on `deps + secrets-check + apk-verify`.
- `env.example` — checked-in template for the secrets file. `make
  secrets-init` copies it to `/Volumes/ring/env/kohler.env`.
- `scripts/env_lib.py` — shared library. Env loading, tool discovery, atomic
  file ops, secure perms, port probes, `RunContext` for per-run logging.
  **Other scripts import from here.** Errors raise `HarnessError` /
  `MissingEnvError`, not `SystemExit`.
- `scripts/harness.py` — master orchestrator. Per-run logfile + versions +
  summary at `~/Library/Caches/kohler-anthem/harness-runs/<ts>/`.
- `konnect-apk/` — checked-in APK (git-LFS tracked). The canonical install
  source. `manifest.json` lists per-file SHA-256s. `make apk-verify` hashes
  the files against the manifest before any install.
- `konnect-apk-patched/` — regenerable, .gitignored. Output of `make
  apk-patch`. The patched + resigned bundle that's actually installed on the
  AVD.
- `patches/Is_b_n_return_false.smali` — the smali we splice in.
- `scripts/apk_fetch.py` — two modes: `--verify` (default) hash-checks the
  in-repo APK against the manifest and detects LFS-pointer state; `--update`
  downloads latest from APKPure with stream + retry + ABI sanity-check, then
  atomically replaces the in-repo APK + manifest.
- `scripts/apk_patch.py` — apktool decompile → replace `Is.b.n()` body with
  `return false` → strip the broken `@null` resource ref → apktool rebuild
  → zipalign → apksigner-sign base + all splits with `~/.android/debug.keystore`.
- `scripts/avd_setup.py` — AVD lifecycle. Installs missing SDK components
  via sdkmanager, creates the `KohlerExtraction` AVD (Pixel 5, Android 11,
  google_apis arm64-v8a) if missing, boots with `-writable-system`, waits
  for boot, runs `adb root` + `adb remount`. Idempotent.
- `scripts/mitmproxy_setup.py` — caches the **complete** `~/.mitmproxy/`
  (cert + private key) so the system-installed cert keeps matching across
  runs. Has `--uninstall` to remove the CA from the emulator. Uses the AVD
  host-gateway (10.0.2.2).
- `scripts/capture_pfx_password.py` — recovers `app_certificate.p12` password
  via a Frida hook on `KeyStore.load(InputStream, char[])` at app launch.
  Only fires if `KOHLER_APIM_CLIENT_CERT_PASSWORD` is missing from the env.
- `scripts/extract_client_cert.py` — `res/raw/app_certificate.p12` →
  PEM via `openssl pkcs12 -provider legacy -provider default`. Output goes
  to `$KOHLER_APIM_CLIENT_CERT_PEM` (a path inside the harness cache).
- `scripts/token_capture.py` — runs mitmdump (with `--set client_certs=PEM`
  so upstream mTLS still works) + Frida in their own process groups, waits
  for the listen port before launching Frida, auto-taps through Konnect's
  permission + login screens, signals the groups on Ctrl-C, parses captured
  flows per-entry (resilient to truncation), atomic-writes structured JSON.
- `scripts/konnect_signin.py` — typed `KONNECT_SIGNIN_STEPS` list with a
  whitelist for safe-text auto-typing. Rejects passwords with shell
  metacharacters.
- `scripts/record_konnect_signin.py` — interactive UI recorder. Dumps the
  view hierarchy + screenshot every 3 s while the user signs in by hand;
  writes a skeleton step list.
- `scripts/secrets_{init,link,check}.py` — bootstrap the env file and the
  `.env` symlink, then validate required keys are present.
- `scripts/doctor.py` — one-shot diagnostics snapshot (tools, env, AVD,
  device, cache, recent runs).
- `scripts/frida_bypass.js` — license (Pairip) / SSL pinning / root /
  emulator-detection bypass injected into the Konnect app at launch. Also
  hooks `KeyStore.load` for password capture.

## Public interfaces

Top-level Make targets (this module is invoked as a CLI):

| target | purpose |
|--------|---------|
| `make harness` | Full pipeline end-to-end (AVD + patched APK + Frida + mTLS) |
| `make deps` | Install brew/pip tooling + Android SDK components (idempotent) |
| `make secrets-init` | Copy env.example → `/Volumes/ring/env/kohler.env` |
| `make secrets-link` | Create `.env` symlink in repo root |
| `make secrets-check` | Validate required env keys |
| `make doctor` | Diagnostics snapshot |
| `make clean-emulator` | Stop + delete the KohlerExtraction AVD |
| `make emulator-mitmproxy-uninstall` | Remove the mitmproxy CA from /system |

Python-level (importable from `tests/unit/credential_extraction/`):

- `env_lib.load_env(path) -> HarnessEnv`
- `env_lib.parse_env_file(path) -> dict[str, str]`
- `env_lib.atomic_write_text(path, content, mode=0o600)`
- `env_lib.wait_for_port(host, port, timeout=10.0) -> bool`
- `apk_fetch.fetch(force=False, allow_pin=True) -> FetchResult`
- `apk_fetch._version_from_url(url) -> str | None`
- `apk_fetch.verify_signing_pin(apk, cache_root, allow_pin=True)`

## Dependencies

- Internal: none (this is a leaf module; it does NOT import from
  `src/kohler_anthem/`)
- External tools (installed by `make deps`): adb, frida (in venv), mitmdump
  (brew + venv), jadx, jq, openssl, xz, apktool, openjdk, sdkmanager +
  avdmanager + emulator + system-image + build-tools (from
  android-commandlinetools cask + sdkmanager).
- Python: `frida-tools`, `mitmproxy` — both into `../.venv` via `make deps`.

## Recent changes

- 2026-05-10: Initial harness build (`feat/emulator-token-capture`).
- 2026-05-10: Full rework after review — atomic FS ops, SIGTERM process
  groups, port-readiness probes, mitmproxy CA cached with private key,
  per-run logfile / versions / summary, secrets bootstrap targets, doctor +
  record-konnect-signin + clean-emulator targets, ABI-mismatch preflight,
  frida-server version-pinned to frida-tools, env_lib library errors instead
  of SystemExit, 48 unit tests.
- 2026-05-10: Konnect APK moved into the repo as git-LFS
  (`konnect-apk/` renamed from `kohler-konnect-3.0.1-apk/`); APKPure
  scraping is now `make apk-update` only (manual refresh path), not the
  default. Brew installs are now real Make file targets using `$(shell brew
  --prefix)` for cross-platform paths. 166 unit tests total.
- 2026-05-10: Added bytecode-level patching (`apk_patch.py`) for Konnect's
  `Is.b.n()` root-detection method — Frida hooks on that method fail to fire
  on AVD due to ART JIT inlining; the smali patch is the reliable path. The
  patched APK is installed with `adb install-multiple -i com.android.vending`
  to satisfy Pairip's installer-package check.
- 2026-05-10: Added Frida-based PKCS12 password recovery + cert extraction.
  `capture_pfx_password.py` reads the `KeyStore.load()` arg at Konnect
  startup; `extract_client_cert.py` converts `app_certificate.p12` → PEM
  (with the OpenSSL legacy provider for RC2-40-CBC).
- 2026-05-10: AVD is the only emulator backend. `make harness` runs
  end-to-end: AVD setup → APK patch → install + permission grant →
  frida-server → mitmproxy CA → conditional password capture → cert extract
  → token capture with auto-UI drive.

## Known issues / open gaps

- `konnect_signin.KONNECT_SIGNIN_STEPS` is empty. The harness now drives
  past `LocationPermissionActivity` and `AzureLoginActivity` Sign In with
  hardcoded coordinate taps in `token_capture.py`. Further steps (email +
  password entry) are still manual.
- APKPure scraping is fragile by nature; if their URL pattern changes the
  user-visible failure is "version probe failed" and the harness falls back
  to the cached APK with a clear log line.
- Konnect's "Sign In" tap fires correctly but on a freshly-booted AVD with no
  cached account state, `/token` doesn't always fire in response — the click
  is registered (toast appears) but Konnect's downstream logic short-circuits.
  When auto-tap doesn't trigger /token, the script prints a warning telling
  the user to interact with the emulator manually.
